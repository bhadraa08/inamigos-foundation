# InAmigos Foundation Website

A modern, responsive, and visually engaging website built for **InAmigos Foundation**, showcasing the organization's mission, vision, initiatives, impact, volunteer opportunities, donation programs, events, and community engagement activities.

## 🌟 Overview

InAmigos Foundation is dedicated to creating sustainable social impact through:

* Education & Child Development
* Women Empowerment
* Community Welfare
* Animal Welfare
* Environmental Sustainability
* Skill Development & Internships

This website serves as the foundation's digital presence, helping visitors learn about initiatives, volunteer, donate, and connect with the organization.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/bhadraa08/inamigos-foundation.git
```

Navigate to the project:

```bash
cd inamigos-foundation
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

---

## 📦 Build for Production

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

---

## 🌐 Deployment

This project is deployed using **Vercel**.

To deploy manually:

```bash
npm run build
```

Connect the repository to Vercel and deploy.
